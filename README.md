# Nissiel, O Eulírico — Vitrine literária

Este repositório publica a vitrine oficial do universo literário de Nissiel, O Eulírico, separada do repositório técnico autoral.

- Domínio: https://nissieloeulirico.com.br
- Hospedagem prevista: GitHub Pages
- Conteúdo arquivado do WordPress: 15 páginas, 38 publicações (incluindo rascunhos) e inventário de 335 arquivos de mídia.
- Navegação: Início, Acervo, Poemas, Salmos, Narrativas, Bestiário, Escritos, Músicas, Entrelinhas, Raiz, Galeria, Coração e Sobre o Autor.

O WordPress original permanece preservado como fonte. O conteúdo integral das páginas e publicações foi copiado para `wordpress-archive/` em HTML com a marcação original do editor de blocos. O inventário de mídia está em `wordpress-archive/media-index.json`; os arquivos binários continuam hospedados no WordPress e são referenciados por seus endereços originais, aguardando uma etapa própria de cópia física.
